# 场景讲解配音模块实施方案

## Context

后端生成流程需要新增配音能力：文稿定稿后调用 yovoice HTTP 服务合成每幕讲解音频，WAV 经 ffmpeg-static 转 64kbps 单声道 MP3 后发布到 CDN。**部署拓扑：整个项目（后端 + 小程序开发环境 + yovoice）将整体迁移到一台显存更大的电脑运行**，`yovoice serve` 与后端同机部署，后端通过 `http://127.0.0.1:8080` 调用；yovoice 进程生命周期独立管理（手动/服务方式启动），后端不负责拉起。推荐模型 IndexTTS 2.5（Q8 3.5GB，支持中文克隆、情绪控制与文本发音标注，可处理景区多音字）。已定稿的产品决策：

- **3MB/2MB 包体闸门不改**。音频不进包目录，发布到 `cdn/audio/{packId}/scene-{id}.mp3`（fastify-static 根路径暴露 cdnDir，URL = `CDN_BASE/audio/{packId}/scene-x.mp3`），天然不占包体额度、不进 manifest。
- 音频元数据（durSec/bytes/sha256）写入 content.json → pack.json 的 scene 字段；小程序按 pack.json 自校验 sha256。
- 小程序默认按幕流播远程 MP3；支持按包「下载音频到本地」离线播放（存 `USER_DATA_PATH/packs/{id}/audio/`），信号差时可用。
- 配音失败不阻塞发布：单幕失败则该幕无 audio、按钮置灰；全部失败整包正常发布（参照立绘降级写法）。
- 单幕时长 >90s 判该幕失败（防 TTS 拖尾复读）。
- yovoice serve 同时只跑 1 个任务，后端全局信号量串行化。

## 实施步骤

### ① 后端端口与 provider

- `server/src/domain/ports.ts`：新增 `VoiceSynthPort { synthesize(text, sceneId): Promise<{mp3: Buffer; durSec: number} | null> }`；`PackSourceInput` 增加 `sceneAudio?: Map<string, {durSec, bytes, sha256}>`。
- 新建 `server/src/infra/providers/yovoice-provider.ts`：
  - 流程：`PUT /v1/jobs/{requestId}`（body `{text, modelId, voiceId}`）→ 2–5s 轮询 `GET /v1/jobs/{requestId}`（409 busy 退避重试）→ `GET /v1/audio/{id}` 下载 WAV → 从 WAV 头 byteRate 算时长 → ffmpeg-static 转 64kbps 单声道 MP3 → 返回 `{mp3, durSec, bytes, sha256}`。
  - 鉴权 `Authorization: Bearer YOVOICE_API_TOKEN`；fetch 与转换函数构造注入（便于单测）。
  - 模块级 Promise 链信号量串行全部请求。

### ② 管线插入

- `server/src/infra/pipeline/generation-pipeline.ts`：
  - `run()` 在 scripts 完成后（L107 后）、`runVariant()` 在 rewrite 后（L264 后）新增「生成讲解音频」阶段：逐幕取文本 `body.split('\n\n').join('')`（v1 兼容 `narration`），合成落 `cdn/audio/.tmp-{packId}/`，元数据随 `sources.write` 传入；`assembler.run` 成功后再换入 `cdn/audio/{packId}/`，然后 `refresh.commit()`；失败/回滚时清 `.tmp`。
  - 整体 try/catch，单幕失败仅该幕无 audio；`YOVOICE_URL` 未配置时跳过配音阶段正常发布。
- `server/src/infra/storage/pack-source-writer.ts` `write()`（L166–183）：scene 项写入 `audio` 字段。

### ③ 装配透传

- `tools/assemble-pack.js`：`buildPack` L104 旁加 `if (scene.audio) item.audio = scene.audio;`；`keepExtras`（L145–160）除 pois 外按 scene id 保留旧 `audio`（防重装丢元数据）。

### ④ 校验与清理（关键坑）

- `tools/validate-pack.js` `main()` L615–620：目录扫描把 cdn 下所有非点开头目录当包，`cdn/audio/` 会报「缺少 pack.json」→ 加 pack.json 存在性过滤（仿 build-manifest.js L112）。
- `server/src/infra/storage/pack-cleaner.ts` `remove()`（L15–25）：删除目标增加 `cdn/audio/{id}` 与 `cdn/audio/.tmp-{id}`。
- `tools/build-manifest.js`、`cdn-store.ts` 不改（音频不在包目录）。

### ⑤ 小程序播放

- `miniprogram/core/loader.js` `decorate`（L99–131）：scene 有 audio 时产出 `audioRemoteUrl`（CDN_BASE + '/audio/' + packId + '/scene-' + id + '.mp3'）、`audioLocalPath`（localDir + '/audio/…'）、`audioReady`（本地文件探测）。
- 新建 `miniprogram/core/audio.js`：单例 `wx.createInnerAudioContext`，play/stop/状态。
- `miniprogram/components/scene/scene.js` L193 `onAudioTap` 接入播放（本地优先，否则远程）；`active` observer 切幕时 stop；`scene.wxml` L57 去掉写死 `is-disabled`，按 `scene.audio` 判定可用性。

### ⑥ 小程序离线下载

- `miniprogram/core/cache.js`：新增独立 storage key `packs:audio`（不能混入 packs:local，markDownloaded L70 会整体覆盖）；复用 `downloadFile`/`verifyFile`（L195–254）串行下载全部幕音频到 `USER_DATA_PATH/packs/{id}/audio/`，按 pack.json 的 bytes/sha256 校验；`remove()`（L92–102）同步清 `packs:audio`。
- `miniprogram/pages/packs/`：已下载包行加「下载音频/删除音频」chip（仿 packs.wxml L112–118 row-del 的 catchtap 模式），进度复用 download() L641 的 showLoading 写法。

### ⑦ 配置与 env

- `server/src/config.ts`：新增 `ttsConfig { url, token, modelId, voiceId, maxSec=90 }`（读 YOVOICE_URL / YOVOICE_API_TOKEN / YOVOICE_MODEL_ID / YOVOICE_VOICE_ID）；YOVOICE_URL 默认 `http://127.0.0.1:8080`（同机部署），留空则流水线跳过配音。
- `server/src/index.ts` L37–48：注入 VoiceSynthPort；`server/.env` 补占位注释；`server/package.json` 加依赖 `ffmpeg-static`。

## 验证

1. 单测：`yovoice-provider.test.ts`（fake fetch 覆盖 completed/failed/409 重试/超时；>90s 判失败；信号量串行断言）；管线测试（装配失败时 `cdn/audio/{id}` 不被污染）；assemble 重装后 audio 字段保留。
2. `npm test`（server）+ `node tools/validate-pack.js --dir cdn` 全量通过（验证 audio 目录过滤）。
3. 当前 MX250 机器：`YOVOICE_URL` 留空跑通「跳过配音」的完整生成回归；provider 全部走 fake 单测，不依赖真实 yovoice。
4. 迁移到新机器后的端到端：装 yovoice CLI + 引擎（CUDA 版）+ 下载 IndexTTS 2.5 模型 + 上传参考音色拿 voiceId → `yovoice serve` 起在同机 → 后端 .env 配好 → 小程序提交生成 5 幕新地名包 → 检查 pack.json 各幕 audio、`/audio/{id}/scene-x.mp3` 可访问、游览页按钮可播；断开 Wi-Fi 验证离线包音频仍可播；删除包验证 audio 目录与 packs:audio 同步清理。
5. 回归：不带 YOVOICE_URL 启动后端，生成流程与现状完全一致（无音频发布）。

## 风险点

- 刷新失败致音频与旧 pack.json 不一致 → 暂存 + 装配成功后换入。
- ffmpeg-static 安装需外网下载二进制 → 迁移部署时在新机 `npm i` 验证。
- 全局串行配音拖长任务占用队列（10 幕 × 数十秒）→ 进度阶段上报 + /health queueLength 观察。
- yovoice serve 重启丢任务状态（内存仅留最近 100 条、中断任务不续跑）→ provider 对轮询 404 按失败处理并降级为无音频，不重试整幕。
